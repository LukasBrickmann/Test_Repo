# Typen, Werte, Objekte
* Ein Typ (`type`) besteht aus einer Menge von Werten (`values`) und einer Menge von Abbildungen bzw. **Operationen** auf Werten dieses oder eines anderen Typs.

* Ein Objekt (`object`) besteht aus einem Typen, einem Wert dieses Typen und einer Identität (`identity`).

## Built-in types (gpt)

| Kategorie                | Typen                                                                             |
| ------------------------ | --------------------------------------------------------------------------------- |
| Special objects          | `NoneType`, `NotImplementedType`, `EllipsisType`                                  |
| Number                   | `bool`, `int`, `float`, `complex`                                                 |
| Immutable sequences      | `str`, `tuple`, `bytes`                                                           |
| Mutable sequences        | `list`, `bytearray`                                                               |
| Set types                | `set`, `frozenset`                                                                |
| Mappings                 | `dict`                                                                            |
| Callable types           | `function`, `method`, `builtin_function_or_method`, `classmethod`, `staticmethod` |
| Module types             | `module`                                                                          |
| Class types              | `type`                                                                            |
| Code and execution types | `code`, `frame`, `traceback`                                                      |
| Iterator types           | `iterator`, `generator`, `coroutine`, `async_generator`                           |
| Weitere interne Typen    | `slice`, `cell`                                                                   |
