# VS Code Settings

* Die Einstellungen von VS Code können auch bequem über die Datei `settings.json` bearbeitet werden, welche unter Linux standardsmäßig hier liegt: `~/.config/Code/User/settings.json`

* Innerhalb VS Code kann die Datei z.B. über <kbd>Strg</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> und dann `Preferences: Open User Settings (JSON)` geöffnet werden.

* Wenn ihr in eurer settings.json den Inhalt aus der in diesem Ordner befindlichen Datei übernehmt, solltet ihr alle Einstellungen haben, wie sie auch auf [Setup](https://proglang.github.io/teaching/26ws/eidp/setup/setup.html) eingerichtet werden.
